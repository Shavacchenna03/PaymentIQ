# PaymentIQ - Payment Reliability & Recovery Intelligence Platform

Synthetic-data fintech analytics project simulating a UPI payments company called PayFlow.
Models end-to-end payment lifecycles, failure patterns, routing dynamics, and customer recovery strategies.
Delivers actionable reliability engineering metrics and business intelligence dashboards.

> **Note:** All data used in this project is synthetic.
